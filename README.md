# Калькулятор элементарных частиц

## Описание
Приложение для расчета параметров элементарных частиц (Электрон, Протон, Нейтрон). 
Позволяет рассчитать удельный заряд (q/m) и комптоновскую длину волны (λ). 
Результаты можно сохранить в Excel-отчет.

## Инструкции по запуску
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите программу: `python main.py`

## Краткая справка
- **Удельный заряд**: отношение заряда частицы к её массе (Кл/кг).
- **Комптоновская длина волны**: характеристика частицы, вычисляемая по формуле λ = h / (mc).
